Lab

AIROU / AIRLAB · 2024 – Present

Undergraduate research supporting autonomous UAV test operations at AIROU — integrating ROS2 subsystems, writing telemetry tooling, developing test procedures, and isolating faults across hardware and software to keep the vehicle flying reliably.

What I Did

  • Improved autonomous system reliability by integrating ROS2 across perception, navigation, and control nodes and verifying end-to-end subsystem communication before bench and flight tests — resulting in more stable command and telemetry links during test events.
  • Shortened time-to-next-test by analyzing telemetry logs in Python and MATLAB, isolating root causes of anomalies, and validating corrective actions across hardware and software subsystems before returning to flight.
  • Improved mission scenario repeatability by building test matrices, checklists, configuration records, and procedure updates between iterations — reducing off-nominal behaviors across indoor flight runs.
  • Strengthened contingency response by isolating communication and power faults, documenting recovery procedures, and executing stepwise corrective actions before returning the vehicle to operation.
  • Supported faster post-test decisions by writing Python-based telemetry and log review scripts to organize data, validate workflows, and flag anomalies for engineering follow-up.
  • Reduced setup errors before flight runs by performing Linux-based system checks, launch sequencing, and telemetry validation across onboard compute, sensors, and control nodes.

What I Learned

  • Autonomous flight reliability is more an operations and test discipline than a software problem — most issues surface in the workflow between iterations, not in the algorithm itself.
  • Good telemetry tooling pays for itself immediately: fast log review means faster root cause identification and faster return to test.
  • Fault isolation across a mixed hardware/software system requires documented procedures, not intuition — the recovery steps have to be repeatable by anyone on the team.
