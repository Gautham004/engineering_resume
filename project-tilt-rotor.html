Tilt-Rotor UAV

YearJune – Aug 2024
RoleResearch Assistant
SupervisorDr. Wei Sun
StatusCompleted

Tools

  • ROS2
  • Pixhawk
  • Mission Planner

Domain

Autonomous Flight · UAV Systems · Flight Control Integration

Supervisor

Dr. Wei Sun

Summer research position developing autonomous flight capabilities for a tilt-rotor UAV — integrating ROS2 with a Pixhawk flight controller and using Mission Planner for flight planning, monitoring, and data analysis.

What I Did

  • Developed autonomous flight capabilities using ROS2, enabling precise control and navigation of the UAV platform.
  • Configured a Pixhawk flight controller and integrated it with the RC system for reliable hardware-software communication.
  • Used Mission Planner for flight planning, performance monitoring, and post-flight data analysis to improve flight reliability.

What I Learned

  • ROS2 as a robotics middleware — how nodes, topics, and the communication layer map onto real hardware in a flight context.
  • Pixhawk configuration and the gap between software autonomy and physical flight controller integration.
  • How to use Mission Planner as an operational tool, not just for setup — reading telemetry, diagnosing flight behavior, and iterating on reliability.
